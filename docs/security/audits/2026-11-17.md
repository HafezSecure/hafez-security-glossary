## 2. Review passes

### Public-repo hygiene (top priority)
This repository is public, so the first question is whether anything secret or private is committed, now or in history.

- **Secrets / credentials:** none. gitleaks over full history found no leaks. A manual grep of the working tree and of every history blob for private keys, cloud tokens (`ghp_`, `AKIA…`, `xox…`), and `password`/`secret`/`api_key` assignments found only the secret-name **detector pattern** inside `scripts/check-docs.mjs:86` (a literal used to flag secret-looking variable names — not a secret).
- **Internal hostnames / IPs:** none. No `hafezinternal`, internal/private IP ranges, or infrastructure identifiers appear anywhere in the tree or history. External URLs in term `sources` are all reputable public references (OWASP, MITRE ATT&CK, NIST/CSRC, CISA, PortSwigger, APWG, AWS docs, GitHub).
- **Unpublished internal info:** none. `README.md` and `SECURITY.md` describe the handbook as private without quoting it; `AGENTS.md`/`CONTRIBUTING.md` instruct never to copy handbook text into this public repo; `docs/handbook-sync.md` names handbook entries by version only.
- **Tracked files:** no build output (`dist/`), `node_modules/`, or `.env` is tracked; `.gitignore` covers `.env*`, `*.pem`, `*.key`, `dist/`, `node_modules/`. `.env.example` reads no variables and carries no values (confirmed by the docs check).
- **Personal data:** one low-impact item — personal Gmail addresses appear in **commit author metadata** (not in any file). See finding `-01`.

### Supply chain / build
- **Lockfile & installs:** `pnpm-lock.yaml` committed; the gate installs `--frozen-lockfile`. `packageManager` pins `pnpm@11.5.0`; `engines.node >=22.13`.
- **Dependencies:** a single production dependency, `yaml@2.8.3` (no transitive deps, `hasBin` but no install/lifecycle scripts). No dev dependencies. No advisories (prod or full).
- **Build-script allowlist:** no `.npmrc`, no `preinstall`/`postinstall`/`prepare` hooks, no `onlyBuiltDependencies` entries needed — pnpm 11 blocks dependency lifecycle scripts by default, so no third-party install script can run. Secure by default.
- **Output encoding / XSS:** this repository emits JSON datasets only (`JSON.stringify`, which escapes correctly); it renders no web page itself. HTML output-encoding of term text is the responsibility of the consumer (the website repository), out of scope here. Term content is plain structured data (YAML front matter + Markdown prose), not executable.
